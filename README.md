Esta pasta é a cópia de trabalho do sistema (branch `copia`), publicada num site separado.
Os projetos ficam nas coleções `projects_copia` / `projectData_copia` do Firestore, separados do
sistema principal (pasta `SISTEMA REDE FTTH`, branch `main`). Na primeira entrada, o painel de
projetos traz uma cópia dos projetos do principal, que só é lido.
